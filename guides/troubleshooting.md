# 按失败位置排查

| 观察 | 先查什么 | 接下来 |
|---|---|---|
| 宿主没有 BW 命令 | 注册来源、打开的项目、是否重启会话；本地 Pi 安装是否含 pi-subagents 扩展 | 对照[安装](installation.md)。仅克隆源码不等于注册。 |
| 找到命令，模型无响应 | 区分模型登录、网关、超时与插件加载；用同一宿主做一次无写入调用 | 记录首个脱敏错误；不要粘贴 token 或整段会话。 |
| 加载了两个同名 Skill | 检查实际正文来自哪个包或全局目录 | 只保留自己选择的注册方式，勿覆盖其他包。 |
| 计划根与预期不同 | 读取仓库共享 CE 配置的 docs_root，不采用本地覆盖值；检查路径是否在仓内且不在 .git/ | 非法值先纠正再写；不要另造第二个 docs/。 |
| 暂停后状态与代码不符 | 比较当前计划、Git 修订、测试状态及原生运行收据 | 区分上次与本次验证；不要让 status 代替实际恢复记录。 |
| Git 已忽略的文件仍显示 | 用 git ls-files 检查是否已被跟踪，用 git check-ignore -v 对照新样本 | 忽略不等于取消跟踪；先保护唯一证据，再讨论处置。 |
| 本地完成而没有 PR | 查看是否有预期远端、认证、可发布分支、未处理审查发现、现有用户改动 | 按原生 Git 交付状态继续，不创建未知远端，不把本地提交报告为远程交付。 |
