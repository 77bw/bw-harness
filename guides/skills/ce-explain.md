# ce-explain：顺着一个问题读代码，不先开改造方案

你接手了解码器，想知道“收到半个帧时，异常是谁抛出的，调用者最后看到什么”。这需要沿实际调用链回答，而非泛讲协议原理。

`/skill:ce-explain 从公开解码入口追踪一条截断输入，指出在哪检查剩余字节、异常经过哪些层、哪个测试能印证。面向刚接手项目的人，只在对话里解释。`

给它目标入口、观察到的行为和读者背景。结果应带源码或测试位置；若测试只覆盖底层，不应据此外推出上层展示行为。这个请求不修改代码。追踪后发现预期与实际不符，再把已查出的路径交给 [ce-debug](ce-debug.md)，无需从头调查。
