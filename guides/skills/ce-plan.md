# ce-plan：把已定需求变成可以照着验证的计划

调用前准备三样东西：目标、不能改的决定、怎样才算完成。若已有 `docs/plans/` 计划，点名它；否则 Agent 可能不知道你是在续写还是开新任务。

```text
/skill:ce-plan 请在 docs/plans 写一个实施计划：前缀为 UTF-8 字节数，空串合法，最大 255 字节。分别写编码和解码的验收用例，不联网、不加 API，不重复访谈。
```

读返回的**实际计划文件**，检查它能否指导别人独立验收：输入「你」应得到哪些字节？256 字节在哪一侧拒绝？明确要求文件时，聊天里的摘要或“是否继续”都不算交付。它不实施代码；确认后把同一路径交给 [ce-work](ce-work.md)。小改动能直接做完并验证时，不必强制新建计划。

执行依据：[ce-plan 正文](../../skills/ce-plan/SKILL.md) · CE `fcb5e3a`（[修订与适配](../../upstream.lock.yml)）；其他宿主的调用方式见[安装指南](../installation.md)。
