# bw-help：不知道选哪个 Skill 时，先问路

你不必先学会 28 个名字。告诉它**现在有什么、哪件事做不了、这次允许做到哪一步**。例如已有旧仓库、不能移动文件，比“帮我治理一下”更容易得到有用的答案。

在旧项目根目录打开 Pi：

```text
/skill:bw-help 这里有能运行的 app.py、旧 CONTEXT.md 和几份实验脚本。我只想知道整理顺序，不安装、不动文件。
```

预期是“先只读诊断 → 记录现有入口的运行结果 → 列出待批文件”以及对应入口，而不是替你执行迁移。若问题换成“中文消息解码失败”，它应引导你先定位原因，而不是强行走新项目初始化。想执行推荐动作时，再明确点名下一个 Skill。
