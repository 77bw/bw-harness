# bw-help：按当前工作选下一步

给出目标、已有工件、卡点，说明是咨询还是执行。它读取当前宿主加载的目标 Skill 正文，需要时读取决定分支的引用；不把指南摘要当执行契约。

`/skill:bw-help 我有当前计划，但上次验证失败。请只读说明从哪里继续。` 应返回实际计划或失败证据、下一步、需要的输入和完成标志，不再做一次访谈。根因未知时可能转 [ce-debug](ce-debug.md)；实验检验数值假设不需要用户体验原型。

明确要求“执行推荐的这一步”时，按宿主可用能力移交，只有真正执行才报告执行结果。单纯问路不会更改项目，也不保证下一阶段已完成。新会话可从 [status 与 CE 原生运行状态](../workflows/session-recovery.md)接续。

执行依据：[bw-help 正文](../../skills/bw-help/SKILL.md) · Matt `6f7f783` 派生（[修订与适配](../../upstream.lock.yml)）；其他宿主的调用方式见[安装指南](../installation.md)。
