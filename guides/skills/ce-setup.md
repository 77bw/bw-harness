# ce-setup：排查 CE 为什么把计划写到了别处

模板已经生成，`ce-plan` 却没在预想的 `docs/plans/` 下找计划。先查 CE 的项目配置，而不是再初始化一次 Python 项目。

`/skill:ce-setup 只检查当前项目 CE 配置与工具状态。告诉我 docs_root 的值、从哪里读到它，以及计划应在哪；不要修配置、改规则或安装工具。`

给它正确的项目根目录和遇到的问题。报告中区分**没有配置**、**配置不合法**、**工具不可用**，再决定是否批准具体修复。原生 setup 除检查外还可以建议改仓库文件，不能把诊断授权当成修复授权。若是从零建 Python 包，入口是 [setup-bw-harness](setup-bw-harness.md)，不是这里。
