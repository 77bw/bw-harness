# ce-doc-review：审查计划文档

在需要「审查计划文档」时使用。先读取当前项目约束与相关测试，不代替用户的写入授权。

Pi 场景示例：`/skill:ce-doc-review 当前计划是否解释了多字节字符与长度单位？`

**预期结果与边界**：以验收缺口和歧义为结果，避免另写同职责文档。

找不到入口时先查[安装与冲突](../installation.md)，不要安装第二份同名插件。Claude/Codex 调用状态见该页；此示例不是跨宿主验收记录。
