# ce-ideate：还没选题时，找几件值得做的事

“本地协议测试太难用”是一个问题，不是一个功能。可能应该改失败信息、减少向量维护，或者缩短回归时间。先看具体摩擦，再选方向。

`/skill:ce-ideate 围绕本地合成消息测试提出三个改进方向。分别给出当前仓库里的依据、受益者和一个低成本验证办法；不要实施。`

提供观察到的痛点和约束，不要只要一份热门功能清单。结果应让你能选出一个方向，也能指出哪些只是假设。可能生成候选想法文档；若只想在对话里讨论，先说明输出范围。已经选定“改善截断报错”的，用 [ce-brainstorm](ce-brainstorm.md) 缩小需求，不用再发散。
