# ce-simplify-code：已知行为正确，再减少重复

同一变更里有三处计算载荷长度，想合并，但不想顺便改接口和错误语义。先准备当前通过的回归测试，再限定简化范围。

`/skill:ce-simplify-code 只简化编码器里重复的字节长度计算。保留公共接口、报错条件和现有边界用例；改前改后跑同一套测试。`

这条请求允许修改指定代码。比较差异时问：重复是否真是同一个业务判断？合并后调用者是否更容易看懂？如果为了少几行而把“字符个数”和“字节数”合成一个变量，应撤回这项建议。不得为了让简化通过而删掉仍有区分力的测试。原因尚未查清的失败先用 [ce-debug](ce-debug.md)。
