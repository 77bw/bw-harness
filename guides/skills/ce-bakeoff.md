# ce-bakeoff：把两个未成形的方案各自做实，再比较

目标已经确定：调用者要能处理连续消息。但“返回剩余字节”和“提供迭代器”都还只是名字，直接投票只会比较印象。

`/skill:ce-bakeoff 为连续帧读取分别展开“返回余量”和“迭代器”两种方案。对同一组空输入、完整帧和半帧给出调用示例与失败处理，只做设计比较，不修改正式代码。`

输入要有同一份简报、约束和评价条件。它会独立发展候选，再比较取舍，可能需要子 Agent 或中间产物；先约定分析范围和写入位置。好结果会指出哪个约束让某一方案胜出，或为什么应组合两者。若两份方案已经足够完整，只需要判断，选 [ce-pov](ce-pov.md)。
