# ce-pov：就一个具体选择给出有条件的判断

你已有一个成形方案：“给只接受单帧的离线工具换成流式接口”。你要的不是更多点子，而是根据现有调用点判断值不值得换。

`/skill:ce-pov 根据当前调用点、兼容性测试和已有 ADR，判断是否应该改为流式接口。先说结论，再给反对理由，以及什么证据会让你改判；不要改文件。`

把候选、比较对象和决策标准说清。结论应区分仓库能证明的事实与对未来负载的假设。外部多模型交叉判断并非必需，未经授权不要把项目内容送出。要了解“现在究竟怎么工作”而非“该不该换”，用 [ce-explain](ce-explain.md)。
