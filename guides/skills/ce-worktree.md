# ce-worktree：让两项 Git 工作互不占用同一工作目录

你正在主工作目录排查 Bug，又想验证另一个分支，不能让切分支影响尚未收尾的文件。Git worktree（附加工作树）让同一仓库拥有另一个独立工作目录。

先在已有 Git 项目里问：`/skill:ce-worktree 我有未提交修改，想并行验证已有分支。先列当前工作树、建议目标路径和分支，不要创建、切换或清理。`

确认目标不是别人的工作树、原改动不会被移动后，再明确批准创建哪一个。创建会修改 Git 元数据并在磁盘写目录，不是只读操作；结束时用 `git worktree list` 核对归属。删除工作树前检查未提交文件，不要把实验唯一副本当缓存清理。单任务开发通常不需要这一步。
