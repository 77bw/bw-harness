# BW Harness

面向 Python 项目的工程 Skill Pack。用 `setup-bw-harness` 生成或诊断项目，用 `bw-help` 选择下一步。推荐 Pi 安装：`pi install git:github.com/77bw/bw-harness@v1.0.0`。重开 Pi，在空目录执行 `/skill:setup-bw-harness`。

从[使用手册](guides/README.md)进入。[本地安装](guides/installation.md)说明包和项目的不同生命周期，[快速上手](guides/quick-start.md)给出可复验的模板测试。
