# Issue tracker: GitHub

When the project uses GitHub Issues, record its verified repository name and existing issue convention here. Link the relevant issue to the CE plan and the plan back to the issue when appropriate. The issue tracks ownership and coordination; the plan owns implementation units and acceptance. Use the project's authenticated GitHub tooling for requested issue operations; setup does not create issues, labels, or remotes. If the project cannot reach the tracker, record what remains unverified and continue the available local work.
