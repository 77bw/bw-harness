# 相界

**阶段**是会话中的一大块工作：面试、实施、质量保证。改变环境的决定属于已完成阶段之间的间隙。中期，继续或拆分有界的支线任务；保持父推理和 CE 的运行。

## 树

在边界处从上到下工作。第一个**是**获胜。

1. **您可以继续本次会议吗？** 如果下一阶段需要当前阶段作为其主要来源，或者有足够的有用上下文来可靠地完成它，请继续。面试→规划过渡通常需要实际的权衡，而不是压缩的猜测。没有固定的令牌阈值。
2. **上下文真的与接下来发生的事情无关吗？** 只有当旧的推理可以被抛弃时，新的上下文才便宜。在改变之前，确认已接受的决定、证据和下一个单元可以找到。切勿仅仅为了整洁的聊天而放弃待决的决定或分离本机运行。
3. **工作需要出差吗？** 当更换主机、仓库或人员，或通过便携式侧调查时，如果需要，请使用已安装的`ce-handoff`。进位指针及其意义。如果同一项目的计划和状态足够，则不要创建重复的永久移交。
4. **有界任务可以独立运行吗？** 使用主机支持的子代理机制委托具有明确输入和可检查结果的任务。保留父会话；请勿用新控制器替换现有的 CE 控制器。
5. **否则，在边界处压缩。** 使用主机支持的上下文功能；保留已接受的决定、有条件的研究证据、相关引用文档、阻碍因素和下一步行动。区分假设与事实。重新打开时，重新检查 Git 和当前产物。

每次用摘要替换实际对话都会失去一些推理。不要将 CE 运行 ID、验证合同或收据简化为通用的“完成”；恢复时使用其来源。
