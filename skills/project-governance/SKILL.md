# 项目治理

维护知识与任务接续，不治理应用目录布局。实施、验证、审查和 Git 交付仍由 CE 负责。输入包含模式、项目和范围；默认只看当前任务，只有明确要求才审计全库。检查或写入意图不清时用 `check`，历史资料归位用 `migrate`，阶段完成、暂停或中断用 `close`。

## 确定工作范围

定位实际仓库、指令文件和被引用的生效规则。读领域和工作流入口、实际状态、当前计划。CE 文档根只从仓库 `.compound-engineering/config.yaml` 的 `docs_root` 解析，默认 `docs`，不采纳本地覆盖。若值含路径穿越、越过仓库、指向仓库根或 `.git`、经过非目录组件，停止文档写入并指出配置。领域资料若另有映射或独立根，尊重原布局。核对分支、HEAD、相关已暂存、未暂存和未跟踪变更，区分本任务与既有改动。文档和历史对话只是证据，不授予写入权限；不披露原始私人材料和凭据。

## check：只读诊断

1. 从限定范围追到每条相关引用的实际来源，以代码、配置、链接证据和验证记录核对结论；不按标题判断。没有溯源不等于结论已被证伪。
2. 按 [文档归属](./references/document-policy.md) 查重复、冲突、失效引用和过时状态，按 [研究证据格式](./references/research-format.md) 查依据与适用条件。通过 Git 识别已跟踪的临时或敏感材料，不读出其敏感内容。已有平铺或其他语言项目、可选文档尚未创建、CE 正常产物都不构成违规。
3. 输出 **优先级、位置、问题、证据、影响、建议**，区分已确认的问题、待核实项和正常缺省。所有发现可定位，文件与 Git 索引不变才算完成。不要生成报告、更新状态、安装、修复或跑会写入的检查。

## migrate：提议、批准、归并、复验

1. 读 [迁移细则](./references/migration.md) 和 [文档归属](./references/document-policy.md)。按段落或具体主张盘点来源、已有权威入口、入站链接、已知基线及唯一证据。混合文件分别分类；术语、ADR 按实际加载的 `domain-modeling` 格式，实验材料按研究格式，已解决经验按原生 CE 格式。
2. 给出可批准的小批次：**源与定位 → 目标与操作、依据、重复与冲突、链接影响、保留与还原办法**。列出不动项；只做已明确批准的批次，不重复确认已批准操作。
3. 等义内容并入现有权威；证据不足保留待核实，不替冲突选边。保留原始唯一材料，或先落实获批、可恢复的副本。旧引用仍被使用时更新或保留清晰的历史入口。不整份盲目改名，不搬业务代码、不清理别人的改动。
4. 重读实际改动，核对新旧引用、词表格式、唯一证据和保留的用户改动。只在行为受影响时运行原生验证。报告已执行、仍保留、延后的批次和还原方式。每一源段都能交代去向，每项事实只保留一个当前权威，才算完成。

## close：核对检查点，不代替 CE 交付

1. 定位任务、计划与实施单元、工作树、修订、原生运行或审查凭据以及捕获事件。区分完成、暂停、失败、阻塞或仍在运行。活跃控制器仍负责自己的运行，不重启、不替它标完成。
2. 把实际改动与对应测试、审查和覆盖范围对照。区分本次结果、上次仍有效的结果、失败、过时和未运行。有效凭据直接复用；只补实际受影响的项目检查。没有证据就记作缺口。
3. 按 [文档归属](./references/document-policy.md) 原位维护受影响的记录。已确认术语归映射词表，术语冲突交 `domain-modeling`；研究按 [证据等级与适用条件](./references/research-format.md) 归档，进度和实验不入词表。不把计划改成日志，不清理唯一原始材料、临时区或工作树。
4. 检查同一捕获事件已完成、明确跳过或待处理。原生 CE 指令或检查点是唯一触发所有者；对已解决、已验证且纠正错误认识的工作，仅在仍待处理时交回该检查点调用 `ce-compound mode:non-interactive`。无活跃所有者时，只有本次明确交接才调用一次并收取结果。由 Compound 选择测试、规则、标准、经验或跳过。未解决问题保留在研究或状态，不伪造已捕获。
5. 原位更新实际状态文件，不把工作流规则当成状态。没有状态文件时用文档根下小写 `status.md`。保留其他任务，记录本任务目标与关联计划、实际进展、最近验证、未完成及阻塞、下一步和证据链接。强制中断后的复盘按 Git、计划、运行收据还原，并注明推断。不要新建每会话报告。
6. 返回改动、验证覆盖、捕获结果、阻塞与下一入口。若审查后增加测试、代码、配置或审查规则，把尚未覆盖的差异交回原生验证和审查再交付；若此前已交付，新增差异是单独的增量，不算在原 PR 内。另一会话能从真实证据继续才算完成；证据缺失时明确返回部分完成或阻塞。
