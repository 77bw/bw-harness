# 撰写标题和正文：证据、教学和品牌门

**您必须完整阅读`references/pr-description-writing.md`**。它定义了价值优先的框架、规模、程序高度（其中PR位于多个PR系列中）、相关工作参考（在重写时保留现有的`Related:`/`Fixes`）、品牌主体规则和预申请审核。如果模式选择识别了一个（仅描述，带有粘贴的 URL、描述更新或在完整工作流程中确认的现有 - PR 重写），则此技能所需的唯一输入是 PR 参考。如果步骤 1（解析分支和 PR 状态）找到现有的 PR，则在重写时将其 URL 传递给步骤 4，以便 PR 模式获取现有主体。在 Stack 模式下，第 5 步（应用和报告）遵循`references/stack-submit.md`中的提交后描述步骤，而不是在此处组成一个默认基础正文。

**构图前的证据决定**。使用用户或调用者提供的产物，并仅按照 `references/visual-evidence.md` 的描述自行截取屏幕截图。永远不要发明证据，也永远不要启动另一个 CE 技能来捕获它。

1. **用户或调用者提供**（URL、markdown image/embed、本地路径）- 合并为 `## Demo`、`## Screenshots` 或 `## Evidence`，并且不要对已显示的内容进行屏幕截图。提供的未进行此更改的 UI 屏幕截图有所不同：它是第 4 项的之前图像，而不是完成的证据。
2. **用户要求提供证据，但没有提供** - 要获取 UI 屏幕截图，请转到第 4 项。对于其他任何内容（录音、演示），请索要产物或告诉他们用宿主捕获它并返回。
3. **没有重大可观察的声明**（内部管道、仅类型、纯重构、惰性文档）- 无需询问即可跳过。按运行时目的而不是扩展进行分类（运行时代理说明/配置/产品内容/策略YAML不能像“文档”一样自动跳过）。
4. **实质性视觉声明**（审查者通过查看呈现的 UI 可以更快或更正确地判断），或者用户要求屏幕截图 - 立即阅读 `references/visual-evidence.md` 并遵循它。当它无法捕获时，它会退回到第 5 项的注释。
5. **否则**（CLI、API、工作流程、排名、deploy/config行为）——写一份关于所执行内容的简明验证说明。如果真正的运行是不可能的（凭证、付费服务、仅部署、硬件、缺少设置），请说出来。不要因为缺少视觉效果而阻止PR创作；测试或手动检查注释都可以。切勿将测试输出标记为“演示”或“屏幕截图”。

**构图前的概念教学门**。使用在 Context 中收集的存储库根，如果您还没有它，则使用 `git rev-parse --show-toplevel` 解析它（仅描述和描述更新模式可以跳过上下文快照）。然后应用下面的普通密钥规则。

**解析两个存储库文件中的普通 CE yaml 密钥。**

- **读取** `<repo-root>/.compound-engineering/config.local.yaml`，然后读取 `config.yaml` (`<repo-root>` = `git rev-parse --show-toplevel`)。丢失的文件将被跳过。 Gitignore 不会改变分辨率。
- **以第一个活动（未注释）值获胜**。对于标量，未设置空；无效值继续下一层，则技能默认。对于列表和地图，现有的键（包括空列表或地图）将替换整个键。
- **不要**将此规则用于 `docs_root` — 该键仅是 `config.yaml`。
<!-- ce-config-layers:end -->

只有 **活动（未注释）** `pr_teaching_section:` 键才有效。以 `#` 开头的行是 YAML 注释，匹配注释的模板键将默默地翻转决策。仅当获胜活跃值恰好为`false`时才关闭教学；缺少的键或任何其他值 → 默认**打开**。同一层顺序解析`pr_teaching_archive:`：仅当获胜活动值恰好为`true`时才打开，否则**关闭**。每次运行的 `archive:on|off` 令牌会覆盖此调用。

- 门**开启** — 判断新颖性并根据引用文档的**步骤 B2** 进行创作。
- Gate **off** — 无需概念处理即可撰写：跳过新颖性判断、`## New concepts` 部分、第 5 步概念预告片和 `ce-explain` 优惠以及完全归档。

**PR 品牌门** 在合成之前。除非此调用包含 `branding:on` 或用户在当前提示中明确要求添加 Compound Engineering 品牌，否则品牌**关闭；将自然语言请求标准化为 `branding:on`。当 `branding:on` 不存在时，`branding:off` 强制关闭。如果两个标记都存在，请停止并报告冲突，而不是猜测。将已解决的品牌决策以及 PR 是新的还是现有的传递到参考的步骤 D，该步骤定义了正文规则。

然后继续参考（步骤 A-E，包括示教门打开时的步骤 B2）。步骤 E 必须在尸体返回之前运行。
